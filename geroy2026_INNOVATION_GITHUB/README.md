# Герой 2026 — интерактивная литературная карта

Готовый многостраничный сайт для **GitHub Pages** по проекту Турсынбай Мадияра «Как нейросеть меняет литературного героя, если перенести его в 2026 год».

## Установка на GitHub
1. Создайте публичный репозиторий, например `geroy-2026`.
2. Загрузите **содержимое** этой папки в корень репозитория: `index.html`, остальные HTML, `styles.css`, `script.js`, папку `assets`.
3. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Выберите **main** и **/(root)**, нажмите **Save**.
5. Откройте ссылку GitHub Pages, которая появится в разделе Pages.

## Возможности
- 10 отдельных страниц, адаптация для телефонов и компьютеров.
- Переключатель XIX век / 2026 год.
- Три современных варианта героя, диалоговые карточки, сравнительная таблица.
- Интерактивная шкала «ДНК героя» (0–10) с сохранением оценки.
- Два реальных режима тестирования по 5 вопросов, ответы выбираются кнопками, результат сохраняется.
- Лаборатория для составления промптов, копирование и чек-лист самостоятельной проверки ИИ.
- Журнал результатов, хранящийся **в localStorage текущего браузера**.

## Важные ограничения
- Никакая нейросеть не подключена: сайт генерирует текст запроса, а не ответ ИИ.
- Результаты хранятся локально: на другом браузере или устройстве их не видно. У сайта нет аккаунтов, базы данных и серверного кабинета учителя.
- Приведённые сравнительные оценки версий — учебные оценки из исходного проекта. Примерные 2,2/4,4 для 15 учеников не представлены как реальные результаты эксперимента.
- Для работы основного функционала не нужны npm, Supabase или секретные ключи.

## Новые интерактивные модули
- **Симулятор решений:** четыре разветвлённых ситуации с выбором поведения, объяснением последствий и свободным обоснованием, печатный маршрут.
- **Детектив текста:** пять эпизодов произведения, сопоставление поступков с качествами, исправление ошибок.
- **Экспорт:** результаты четырёх лабораторий можно сохранить локально в JSON для работы над исследованием. Это не облачная аналитика и не подключённая нейросеть.
